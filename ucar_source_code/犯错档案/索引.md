# 犯错档案索引

本目录（`犯错档案/`）按日期拆分记录仿真/实车开发中出现过的错误。**查看本索引 → 定位主题或日期 → 只读对应日期文件**，不必读完所有文件。

## 记录格式

每个条目固定四段式（实车异常可用 **处理** / **对比** / **结论** 替代 **修复**）：

```markdown
### YYYY-MM-DD：错误标题（标题必须包含可搜索的技术关键词，如 CRLF、NaN、nounset）

- **现象**：
- **原因**：
- **修复**：
- **预防**：
```

## 维护规则

- **新增条目**：append 到当天文件 `犯错档案/YYYY-MM-DD.md`（不存在则创建），并在本索引两处登记：`## 主题索引` 归入最接近的主题行、`## 按日期` 追加标题。
- **检索**：改代码前先读本索引，按主题或 `grep` 关键词定位日期文件，只读相关文件。
