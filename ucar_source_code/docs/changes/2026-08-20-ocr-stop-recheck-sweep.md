# OCR 内墙 25cm 后退复核与尾部朝挡板停车

## 行为

首次 OCR 识别并完成雷达/地图墙点定位后，主流程使用 `ocr_stop_offset_m=0.25` 到达原先认定的墙内 25cm 停车点，车头朝向墙面。
随后使用 `ocr_recheck_backoff_m=0.25` 计算原停车点后方 25cm 的验证位，并通过普通导航直接到达该坐标（不发送倒车速度指令）；验证位从墙面法向 `-45°` 以受控角速度连续旋转到 `+45°`，旋转过程持续抓取 OCR 帧。
识别到与首次类别一致的结果后停止扫读并保留二次识别记录；完整范围内都未确认则任务报错，不继续播报或仿真。
确认成功后，复核射线会重新与地图墙边界求交，并匹配最近的编号墙点。若编号发生变化，纠正后的墙点重新吸附到 0.25 米网格，再由该墙点向内计算 25cm 停车位；若编号未变化，则保留首次雷达实测得到的连续沿墙位置。随后主流程以车头朝墙面的姿态导航到最终坐标，再原地旋转到墙面法向反向，即车尾朝向挡板，然后执行播报或仿真。

这次复核针对的是“0.25 米偏差”，也就是吸附到 0.25 米网格时可能错一格；复核帧保存曝光请求时的 SLAM 地图位姿，使用“地图位姿 + 实测朝向射线”重新定位墙点，不把无法从当前 OCR 帧计算出的纠正位置静默猜出来。
