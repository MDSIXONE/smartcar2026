# 2026-08-15：一次规划 + 转向降速 + 终点只调朝向（三参数试跑）

## 目的

实车在 OCR 巡航前往下一目标时出现"先走一条路，靠近障碍后突然换另一条路，
车体来不及转弯直接撞击"。经代码链路分析，三个因素叠加导致该现象：

1. `planner_frequency: 5.0` 使全局规划器以 5 Hz 周期性重规划；全局动态障碍层
   对中间障碍（如 431）的标记受激光噪声/遮挡影响时隐时现，全局路径在障碍
   近旁反复换侧。每次几何变化的 `setPlan()` 都会重置控制器状态，航向误差突变。
2. Point 模式 `heading_slowdown_min_scale: 1.00`，航向误差突变后仍以
   `0.35 m/s` 全速画弧（最小转弯半径约 `0.44 m`），窄巷内转向不足。
3. 终点姿态调整阶段 `final_linear_x_gain: 1.0` 同时执行朝向对准与前后位置
   修正，车辆定点到墙内后反复前后调整。

本轮按用户要求只改上述三个参数试跑，观察效果后再决定是否保留或进一步修改。

## 涉及文件（均已同步小车，YAML 无需编译）

1. `ucar_ws/src/ucar_nav/config/testnav20260721/move_base_params.yaml`：
   - `planner_frequency: 5.0 → 0.0`。关闭周期性全局重规划：一次规划后仅在
     CymPlanner 前视判障失败（`controller_patience=0.5 s` 内）时事件驱动重规划，
     消除 5 Hz 在近障碍处反复换侧导致的急转。
2. `ucar_ws/src/cym_planner/config/ucar_cym_planner_params.yaml`（mode1_point）：
   - `heading_slowdown_min_scale: 1.00 → 0.00`。线速度按
     `max(0, cos²(航向误差))` 缩放：换路后大角度对准先原地转向、基本不前进；
     直行（误差 ≈0°）仍为全速，车头对准后自动恢复。
   - `final_linear_x_gain: 1.0 → 0.0`。距离目标 < 0.05 m 进入终点阶段后只做
     朝向对准，不再前后修正位置，消除墙边定点来回调整。

## 验证结果

- 本机两份 YAML 以 UTF-8 显式编码完成 `yaml.safe_load` 解析，语法通过。
- 已 scp 至小车（192.168.8.231），两端 SHA-256 一致；车端 grep 确认三处

## 已知限制

- 本次为**试跑配置**，未经实车验证；用户实测后再决定是否保留。
- `planner_frequency: 0.0` 下仍会由局部判障失败事件驱动重规划，也能响应新目标
  与守卫取消，并非彻底禁止重规划；若实测中"换路"仍在路径更新后出现，说明
  触发源是事件驱动重规划或目标守卫，需要继续按日志定位。
- `heading_slowdown_min_scale: 0.00` 不是硬阈值：航向误差 45° 时仍保留约 50%
  线速度；若要求"误差超过某角度必须原地旋转"，需要另行增加角度门槛。
- `final_linear_x_gain: 0.0` 后终点位置只受任务层 `arrival_tolerance: 0.15 m`
  验收，CymPlanner 在 0.05 m 内停止平移；若实测到点位置偏大，可再评估该
  0.05 m 阈值是否放宽（该值当前为源码常量，非 YAML 参数）。
