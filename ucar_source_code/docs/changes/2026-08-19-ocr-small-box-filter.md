# OCR 遮挡小框候选过滤（2026-08-19）

## 目的

处理生产 OCR 对准时，锥桶遮挡车体与远处墙牌的视线：OCR 仍可能返回高置信度、但可见区域很小的文字框。旧逻辑只检查文字和置信度，会停车、恢复候选角度并进入连续对准；对准失败后又继续 360° 扫描，同一远处墙牌会再次触发，表现为一直尝试对准。

## 改动

- 三套 `production_task_perception.py` 增加 OCR bbox 面积计算和候选面积门。
- 三套 `production_task_2026.py` 在移动 OCR、整圈 OCR 和末帧 OCR 进入候选处理前统一检查面积。
- 新增 `ocr_candidate_min_bbox_area_px` 参数；三套 launch 当前设为 `2400.0`，对应 `6 × (20px 对准容差)^2`，用于进一步过滤远处或被锥桶遮挡的残缺框。
- 小框会记录 `PRODUCTION_OCR_CANDIDATE_IGNORED_SMALL`，直接丢弃当前运动帧，不停车、不恢复角度、不进入 `observe_wall`。
- `51×38=1938px²` 的边界样本现在会被 `2400px²` 门槛过滤；测试中的 `61×41=2501px²` 有效框仍会通过。

## 已知限制

面积门只能过滤“可见框过小”的遮挡候选；若锥桶遮挡后仍产生足够大的 OCR 框，仍需依赖对准后的激光墙距残差拒绝。正式车端验证前应确认车辆零速、`/odom_raw` 有限、TF 和 `/scan` 新鲜。
