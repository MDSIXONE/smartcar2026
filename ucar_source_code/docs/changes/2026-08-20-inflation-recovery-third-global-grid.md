# 恢复阶段全局膨胀按三分之一栅格降低

日期：2026-08-20

## 目的

恢复逻辑频繁丢失路径时，降低每个恢复阶段对全局代价地图的突变幅度。局部地图继续每阶段降低 1 个栅格，全局地图改为每阶段降低 1/3 个栅格。

## 改动

- `local_reduction_step` 保持 `0.020m`，对应 local costmap 的 `0.02m` 分辨率。
- `global_reduction_step` 从 `0.005925m` 改为 `0.00395m`，对应 global costmap 的 `0.01185m / 3`。
- 更新 `cym_planner` 恢复调度 gtest：`0.224m → 0.22005m → 0.21610m`。
- 更新当前运维说明中的首阶段全局半径：point3 前 `0.21m → 0.20605m`，point3 后 `0.224m → 0.22005m`。

恢复阶段数量、最低半径 `0.05m`、局部步长和取消旋转恢复的策略不变。

## 部署与验证

- 本地完成 YAML、C++ 测试源码和文档静态检查。
- 车端仅在 Ubuntu 18.04/ROS Melodic 上构建 `cym_planner`，再同步导航参数和构建产物。
- 车端恢复调度 gtest 应为 `3/3`；未启动任务、未发送运动指令。
- 参数需要在车辆安全停止后重启 `move_base`/2026 主流程才生效。
