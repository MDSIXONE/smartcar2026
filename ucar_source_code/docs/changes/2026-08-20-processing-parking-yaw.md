# 2026-08-20 处理区停车朝向修正

## 目的

修复处理区停车目标朝向反转的问题。此前目标 yaw 使用“停车点指向墙面交点”再加 `180°`，导致车头背向墙面；而 `CymPlanner` 的 point 模式只输出非负 `linear.x`，车辆在目标位于车后时会保持 ACTIVE，最终等待超时。

## 改动

- 标准、省赛/国赛、额外三套 `production_task_2026.py` 的停车 yaw 改为停车点直接指向墙面交点的 `bearing`。
- 三套处理区几何回归测试增加停车 yaw 断言；以墙点 300 为例，期望方向为 `+90°`。
- 不修改 CymPlanner，不改变全局 `linear.x` 语义，也不增加倒车控制。

## 验证与上线

- 本地三套处理区几何测试、Python AST 和 `git diff --check` 通过后同步到车端。
- 车端仅更新源文件，未主动重启 ROS 或发送运动指令；运行中的 Python2 进程不会热加载，需下一次安全重启 2026 主流程后生效。
- 尚需在安全条件满足时进行一次真实处理区停车验证，确认车辆车头朝向墙面且能完成目标收敛。
