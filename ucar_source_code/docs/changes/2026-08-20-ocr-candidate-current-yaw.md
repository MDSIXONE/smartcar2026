# 2026-08-20 OCR 候选停车取消旧朝向恢复

## 现象

OCR 在完整旋转中识别到候选后，车辆先停车，再向异步 OCR 请求时记录的旧 yaw
反向旋转，现场表现为“识别到 OCR 后马上往反方向转”。

## 原因

异步 OCR 返回的是此前请求的画面，而请求完成时车辆已经继续旋转。任务原先调用
`restore_ocr_capture_yaw` 回到旧 yaw，导致当前姿态发生反向转动。

## 修复

三套 `production_task_2026.py` 删除 OCR 候选处理中的旧 yaw 恢复；车辆停车后直接进入
`observe_wall`，由该流程重新抓取当前姿态的最新画面。保留候选请求时间和请求位姿字段，
用于观察记录审计；不改变 OCR 连续对准、激光测距和类别去重逻辑。

## 生效与验证

- 本地三套几何测试通过：标准 `100/100`、额外 `116/116`、国赛 `101/101`；ROS/Python2 用例按环境跳过。
- 三套脚本 Python2 语法检查、三套 `roslaunch --nodes` 通过。
- 三套任务脚本和三套 `2026.launch` 已上传车端并完成 SHA-256 校验；未重启 ROS、未发送运动指令。
- 下一次安全重启国赛主流程后，OCR 候选日志后不应再出现 `restore capture yaw`。
