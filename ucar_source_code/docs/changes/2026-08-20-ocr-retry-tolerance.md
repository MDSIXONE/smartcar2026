# OCR 对准超过五次后放宽像素容差

日期：2026-08-20

## 现象

OCR 对准时误差从 `65px` 缓慢下降到 `35px` 左右，前五次仍未进入基础 `30px` 容差，车辆继续重复对准。

## 修复

三套 2026 主流程使用 `ocr_alignment_retry_tolerance_increment_px=30.0`：

- 第 1～5 次使用基础 `ocr_alignment_tolerance_px=30.0`；
- 第 6 次及以后使用 `60.0px` 临时容差；
- `PRODUCTION_OCR_BOX` 日志打印当前实际 `tolerance_px`，便于确认是否触发放宽；
- 保留连续视觉伺服、相机帧新鲜度检查和两次发散中止。

新增三套几何回归用例，验证固定 `40px` 误差会在第 6 次通过，而不是继续到第 7 次。

## 验证与部署

- 三套脚本 Python 语法和 launch XML 静态检查通过。
- 车端 Python2 编译通过，三套运行脚本、launch 和几何测试已同步。
- 未重启 ROS、未发送运动指令；运行中的任务需安全重启后加载新逻辑。
