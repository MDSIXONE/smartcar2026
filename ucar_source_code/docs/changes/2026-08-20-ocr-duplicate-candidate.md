# OCR 单点重复目标类别修复

## 目的

修复单点 OCR 旋转期间反复识别同一目标类别，导致车辆重复停车、重复对准和重复测距的问题。

## 改动

- 三套 `production_task_2026.py` 在一次 360° 扫描内增加 `handled_categories`；同一类别完成第一次候选处理后，后续候选直接跳过并继续旋转。
- 保留预记录类别的第二轮语义：当预记录类别成为当前 `target_category` 时，仍允许第一次正式处理；该轮后续重复候选不再重入。
- 三套几何测试增加“目标类别重复候选只调用一次 `observe_wall`”回归用例。
- 运维文档补充 `PRODUCTION_CATEGORY_SKIP_TURN_DUPLICATE` 日志含义。

## 验证

- 修复前车端 Python2 回归用例失败：第二次电子产品候选仍返回 `True`。
- 修复后三套车端 Python2 定向回归应全部通过；本机无 ROS Python 依赖，任务类测试按设计跳过。
- 未启动 2026 主流程，未发送运动指令。

## 已知限制

运行中的 Python2 任务不会热加载脚本；必须在车辆安全停止后重启实际 `2026.launch` 才会加载修复。
