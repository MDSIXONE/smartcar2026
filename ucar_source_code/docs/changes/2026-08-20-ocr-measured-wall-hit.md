# OCR 联合实测雷达点与地图墙点

## 变更

三套 2026 主流程在 OCR 墙面观察阶段同时计算：

- `measured_wall_hit_map`：`map -> laser_frame` 位姿沿前向实测距离投影的真实雷达命中点；
- `forward_ray_wall_intersection_map`：同一射线与编号网格墙体边界的地图交点。

两点通过 `ray_range_agreement_m=0.30m` 做一致性检查。墙点编号改为使用实测命中点匹配，
并真正启用已有的 `wall_match_max_error_m=0.18m`；匹配误差过大的候选会被拒绝。

处理区停车时，地图交点只判定墙体边界方向，实测命中点决定沿墙位置、内缩停车坐标和停车朝向。
因此地图墙体存在局部坐标偏差时，最终停车点仍优先跟随雷达实际看到的墙面位置。
