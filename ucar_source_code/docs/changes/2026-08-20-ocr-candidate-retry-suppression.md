# OCR 同类候选重复对准抑制

## 改动

到点 OCR 扫描中，同一类别第一次候选进入停车、恢复候选帧角度和墙面对准；如果这次对准失败，本轮扫描将该类别加入拒绝集合。后续同类 OCR 候选只丢弃当前帧并继续原方向旋转，不再重复触发停车和反向恢复角度。

## 原因

车端日志显示，`电子产品生产车间` 候选对准失败后，扫描器仍反复接收同一类别候选，导致小车在同一物理点反复执行反向恢复和对准，表现为“转过去、丢失、再反向转”。

## 验证

- 三套生产任务脚本通过 Python 语法检查。
- 三套几何测试新增“拒绝候选不在同一整圈重复处理”用例；本机因无 ROS Melodic 运行时跳过 ROS 依赖用例，需在车端 Python 2/Catkin 环境完成最终回归。
