# 项目黑话词典

## 部署

- **等价说法**：同步到小车、下发车端、更新车端代码
- **含义**：按当前动态网络地址，将本次变更同步到小车端，并在 Ubuntu 18.04 / ROS Melodic 环境完成只读校验；需要编译的代码必须在车端编译。
- **前置条件**：确认车端动态 IP；确认没有正在运行的相关任务节点；涉及运动前确认 `/odom_raw`、TF 和零速度安全门。
- **精确动作**：
  1. 从当前网络信息动态确认 `$CAR_IP`，不使用过期固定 IP。
  2. 只同步本次涉及的文件，不在车端创建备份目录或归档文件。
  3. 在车端校验文件内容；若涉及编译，在车端 Ubuntu 18.04 / ROS Melodic 编译。
  4. 按安全门确认后重启对应主流程，并确认无残留启动终端。
- **不是**：不是在本机编译后复制构建产物；不是启动小车本机 roscore；不是在任务运行中热修改参数或直接触发运动测试。
- **权威来源**：`docs/deployment.md`、`docs/operations.md` 的“生产任务 Python2 源码部署”和“OCR 内墙停车分阶段膨胀”章节。
