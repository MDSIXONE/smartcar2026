# 2026-08-18

## Windows 默认编码读取 UTF-8 源码导致测试误报

- 症状：新增调试程序的 AST 静态测试在 Windows 本机报 `UnicodeDecodeError`，而源码本身语法没有问题。
- 原因：测试使用内置 `open()`，未显式指定 UTF-8；当前 PowerShell/Python 环境按 GBK 解码。
- 预防：AST 读取带编码声明的 UTF-8 源码时使用二进制模式；JSON 等文本资源显式使用 UTF-8，并在本机执行一次定向测试。
- 关联变更：`CHANGE_LOG.md` 中的 2026-08-18 70 冲刺速度调试程序。

## 车端已有 Catkin 白名单导致包级构建未执行

- 症状：车端直接执行 `catkin_make --pkg ucar_2026_national` 时，CMake 只遍历已有白名单 `usb_cam`，随后报 `No rule to make target 'ucar_2026_national/all'`。
- 原因：工作区 `CMakeCache.txt` 的 `CATKIN_WHITELIST_PACKAGES` 限制了本次包级构建。
- 预防：先记录原白名单，临时使用 `--force-cmake -DCATKIN_WHITELIST_PACKAGES=ucar_2026_national` 构建和测试，完成后恢复原值；本次已恢复为 `usb_cam`。
- 关联变更：`CHANGE_LOG.md` 中的 2026-08-18 70 冲刺速度调试程序部署。

## PowerShell 变量名与内置 `$Error` 冲突

- 症状：用 `$error` 保存角度差时，PowerShell 报变量为只读，后续筛选命令全部误报。
- 原因：PowerShell 变量名不区分大小写，`$error` 实际命中了内置的 `$Error` 自动变量。
- 预防：PowerShell 临时变量避开 `$Error`、`$Input`、`$Args` 等自动变量，使用语义明确的名称如 `$angleDelta`。
- 关联变更：2026-08-18 QR 扫描方向扩展。

## 独立调试部署不应同步国赛共享网格坐标

- 症状：独立 70→坡顶调试入口部署时把本地网格 JSON 同步到车端，导致车端共享国赛任务的 70 点坐标被改为 `(2.32, 1.68)`。
- 原因：把调试程序的运行时资源与国赛主任务共享资源混在同一次部署中处理。
- 预防：独立调试入口只部署脚本、launch 和测试；网格 JSON 只读，不上传、不改写。若已误同步，按车端原始 `(2.25, 1.75)` 恢复并做两处记录核对。
- 关联变更：`CHANGE_LOG.md` 中的 2026-08-18 70 点坐标回滚与调试入口隔离。
