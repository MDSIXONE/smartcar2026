# 2026-08-12

### WSL p9_client_rpc 阻塞 Noetic catkin_make

- **现象**：WSL 部署副本执行 `catkin_make -j2` 时，`cmake_check_build_system` 的 CMake 子进程长期为 D 状态、CPU 为 0，等待点为 `p9_client_rpc`。
- **原因**：WSL 文件系统 9P 调用未返回，不是 bridge 的 Python 语法、ROS Master 或 Gazebo 进程错误。
- **修复**：仅向本次确认的构建进程树发送 SIGINT，确认其退出且未遗留 ROS/Gazebo/bridge；独立 Python 3 `--help` 与 `py_compile` 验证通过。
- **预防**：WSL 构建无输出且 CMake CPU 为 0 时先检查 `wchan`；记录 `p9_client_rpc` 后不要反复并发构建。待 WSL 文件系统恢复后从干净 shell 重跑，不删除 build 或未跟踪资产。
