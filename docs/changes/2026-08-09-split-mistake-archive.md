# 犯错档案按日期拆分 + 新增主题/日期索引

## 目的

把单一 `犯错档案.md`（1031 行，约 50KB+，单次读取即触发截断）按方案 2 重组为
「小索引 + 按日期分类的条目文件」，让 AI 在改代码前查档案时：

1. 一次全读索引即可获得全部条目概览（主题 + 日期两级定位）；
2. 按主题或 `grep` 定位后，只读对应日期文件，单文件远小于读取上限；
3. 不再需要从头分段读完 1000+ 行才能找到相关历史错误。
